# 客户端安装与自启

客户端要在一体机上做到两件事：**开机自己起来**、**学生不好关掉**。

这份文档讲怎么装、怎么防、怎么卸。

---

## 一、先决条件

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| Python | 3.10+（只有开发模式需要，打包后不用） |
| 权限 | 安装和卸载都要管理员 |
| 网络 | 能访问服务端域名（wss 走 443） |

---

## 二、安装

### 方式 A：打包安装（推荐）

```bash
pip install pyinstaller
pyinstaller build/mythclass.spec
```

得到 `dist/MythclassClient.exe`。把它和 `build/` 目录一起拷到一体机，然后：

```powershell
# 管理员身份打开 PowerShell
cd build
.\install-service.ps1
```

脚本干了这些：

1. `dist/MythclassClient.exe` → `%ProgramFiles%\Mythclass\MythclassClient.exe`
2. 生成配置 `%APPDATA%\Mythclass\config.json`
3. 建两个计划任务：
   - `MythclassClient`：登录时以 SYSTEM + 最高权限启动
   - `MythclassGuard`：开机时启动守护进程
4. 写当前用户 `Run` 键（保险，双份自启）
5. 目录权限收紧：SYSTEM 和 Administrators 全权，普通用户只读

### 方式 B：开发模式

没打包也能用，靠本机 Python 跑：

```bash
pip install -r requirements.txt
python -m mythclass --console
```

`install-service.ps1` 在仓库根的 `dist\` 里找不到 `MythclassClient.exe` 时，会自动走这条路。

### 手动验证

```bash
python -m mythclass --status
```

会打印机器 ID、连接状态、记录条数、支持的命令。

## 三、自启的三种做法

脚本用完前两种，第三种看需要。

### 1. 计划任务（SYSTEM 权限）

```powershell
schtasks /Create /TN MythclassClient /TR "C:\Program Files\Mythclass\MythclassClient.exe" /SC ONLOGON /RL HIGHEST /RU SYSTEM /F
```

好处：SYSTEM 权限最高，学生账号杀不掉它。

### 2. 注册表 Run 键

```powershell
Set-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'Mythclass' -Value '"C:\Program Files\Mythclass\MythclassClient.exe"'
```

好处：简单可靠。坏处：当前用户能改。所以两种一起用。

### 3. 注册成 Windows 服务

要用 `nssm`：

```powershell
nssm install MythclassClient "C:\Program Files\Mythclass\MythclassClient.exe"
nssm set MythclassClient Start SERVICE_AUTO_START
nssm set MythclassClient ObjectName LocalSystem
nssm start MythclassClient
```

注意：服务方式跑在 Session 0，**抓不到用户桌面的屏，也看不到音频会话**。

所以屏幕和音频这两块，服务方式不适用。要用计划任务（跑在用户会话里、但以高权限启动）。

## 四、防关闭

### 进程保护

`config.json` 里 `protectProcess: true`（默认）。

客户端启动时拉起一个跟班进程（`MythclassClient.exe --guard`），它每 4 秒看一次客户端还在不在。

**怎么判断活着？不看 PID。** PID 会复用；计划任务里那个 `--guard 0` 更是永远被当成「已死」，于是每 10 秒空拉一次。现在改成问客户端自己的单实例互斥体 `Global\MythclassClientMutex` 在不在——这才是「它到底跑没跑」的准话。不在就拉起来，一般几秒内回来。

两个必须有的细节：

- 跟班自己也有互斥体 `Global\MythclassGuardianMutex`，**同时只允许一个**。否则每被杀一次就多攒一个跟班，几个跟班互相打架、反复创建又立刻退出的僵尸进程。
- 老师在托盘里正经退出时，客户端会先写一个 `guardian-stop.flag`，跟班看到就自己退场，**不会把人拉回来**；下次正常启动时这个标记会被清掉，保护重新生效。

跟班自己也由计划任务 `MythclassGuard` 兜底。

### 禁用任务管理器

```powershell
# 客户端设置里勾一下就行，等价于：
Set-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Policies\System' -Name DisableTaskMgr -Value 1 -Type DWord
```

**默认关闭**。要禁就在客户端设置里勾上「禁用任务管理器」并保存，通常立刻生效，个别机器注销一次。

它只作用于当前用户，而且 HKCU 这个键当前用户自己也能改回去——所以它只是抬高门槛，不是铁壁。真正让人关不掉客户端的是进程保护、SYSTEM 计划任务和目录权限这三样。

想关掉：设置里取消勾选，或者：

```powershell
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Policies\System' -Name DisableTaskMgr
```

### 目录权限

脚本执行了这几条：

```powershell
icacls "C:\Program Files\Mythclass" /inheritance:r
icacls "C:\Program Files\Mythclass" /grant "SYSTEM:(OI)(CI)F"
icacls "C:\Program Files\Mythclass" /grant "Administrators:(OI)(CI)F"
icacls "C:\Program Files\Mythclass" /grant "Users:(OI)(CI)RX"
```

学生账号只能读，删不掉也改不动。

## 装哪个版本：优先用「目录版」

打包出来有两种，功能完全一样，只是分发形态不同：

| | 单文件版 | 目录版（推荐） |
|---|---|---|
| 产物 | 一个 `MythclassClient.exe`（57 MB） | 一个文件夹，里面有 exe + 依赖（约 133 MB） |
| 启动 | 每次**解包** 90 MB / 一千多个文件到 `%TEMP%\_MEIxxxxxx` | 直接读文件夹，不解包 |
| 启动速度 | 慢（每次都要解包） | 快 |
| 临时目录 | 每跑一次留一份，**实测正常退出也不清** | 不留任何东西 |

### 为什么单文件版会报「Failed to start embedded python interpreter!」

那是 PyInstaller 引导层弹的，意思是「连解包/启动内嵌 Python 都失败了」。
单文件版每次启动都要往 `%TEMP%` 解开 90 MB，这一步失败就报这个错：

- 临时目录被塞满（这台机器实测攒过 **1.4 GB** 的解包残留）
- 杀软把刚解出来的 `python312.dll` 删了
- 解包目录被占用，或者 exe 正在被覆盖

**被强杀时（任务管理器结束、跟班互杀）残留一定留下**，于是越用越容易报错。
教室机器磁盘小、又常年不重启，最容易中这个。

**目录版没有解包这一步，这个错基本不会出现。**

### 怎么装

```powershell
# 目录版：整个文件夹拷过去（可以先压成 zip 再解）
# 放在任意目录，双击里面的 MythclassClient.exe 即可
Xcopy /E /I /Y dist-onedir\MythclassClient D:\MythclassClient
```

要手动清掉单文件版留下的残留：

```powershell
Get-ChildItem $env:TEMP -Directory -Filter "_MEI*" | Remove-Item -Recurse -Force
```

### 更新时别在客户端运行时覆盖

正在跑的 exe 被覆盖会变成半新半旧的文件，下次启动就报引导层错误。
正确顺序：**先在托盘退出客户端 → 再覆盖文件 → 再启动**。

### 禁止上网（白名单模式）

**默认关闭**，老师在教师端点「禁止上网」才生效，需要管理员权限。

老实现是一句 `netsh advfirewall firewall add rule dir=out action=block`——
不带任何过滤条件，**连客户端自己到服务端的连接也一起掐掉**。
结果是老师再也发不出「放开上网」，那台一体机只能人到跟前用管理员解锁。

现在改成白名单模型：

```
1. 把三个配置文件的「默认出站动作」改成 Block
2. 只放行这几样：
     服务端 IP 的 443    ← 控制通道，命根子
     DNS 53              ← 得能重新解析服务端域名（Cloudflare 的 IP 会变）
     DHCP 67/68          ← 别把 IP 弄丢
   回环不用管，Windows 防火墙本来就不拦
3. 改之前的默认策略记在 netban.json 里，放开时原样还原
4. 保险：到点自动放开（默认 60 分钟，设置里可改；填 0 表示不自动放开）
```

而且客户端每 5 分钟会重新解析一次服务端域名，IP 变了就更新放行规则，
所以 Cloudflare 换 IP 也不会把控制通道弄断。

**为什么故意不放行「本地网段」**：默认网关通常就是 `192.168.x.1`，
放行本地网段等于把路由器也放行了，外网照样通，禁网就成了摆设。
代价是局域网里其他教学工具（走非 443 端口的）也会被拦，这是预期内的。

**怎么用**：教师端控制台 →「命令」→「禁止上网」（填分钟数）→「放开上网」解除。
被禁网期间那台机器仍然在线，老师随时能解除。

### 还没做的

- 驱动级保护（要签名，成本高）
- 互锁多进程（现在的跟班 + 计划任务够用，再加会互相打架）

## 五、配置文件

位置：`%APPDATA%\Mythclass\config.json`

```json
{
  "clientUid": "",
  "clientName": "教室一体机",
  "adminPasswordHash": "",
  "protectProcess": true,
  "disableTaskManager": false,
  "autostart": true,
  "complianceAccepted": false,
  "servers": [{ "name": "官方服务器（不可删除）", "url": "wss://mythclassapi.ryokuryuneko.top", "official": true, "enabled": true }],
  "watchDirs": ["C:\\Users\\Public\\Desktop"],
  "maxLogCount": 5000,
  "maxLogSize": 209715200
}
```

- `clientUid` 留空就自动算（MAC + 主机名 + 机器 GUID 的哈希）
- `servers` 里官方那条删不掉，代码里写死了
- 改完配置要重启客户端

相关文件：

| 文件 | 位置 |
|---|---|
| 配置 | `%APPDATA%\Mythclass\config.json` |
| 记录库 | `%APPDATA%\Mythclass\records.db` |
| 日志 | `%APPDATA%\Mythclass\client.log` |
| 程序 | `%ProgramFiles%\Mythclass\` |

## 六、托盘操作

| 操作 | 结果 |
|---|---|
| 左键单击 | 关于窗口（机器 ID 在这） |
| 右键 → 关于 | 同上 |
| 右键 → 设置 | 要密码，默认 `admin123`（配置里只存哈希） |
| 右键 → 状态 | 连接状态与记录统计 |
| 右键 → 退出 | 也要密码 |

第一次进设置，请把密码改掉。界面会一直提醒你。

## 七、卸载

```powershell
# 管理员 PowerShell
cd build
.\uninstall-service.ps1
```

顺序：停任务 → 杀进程 → 放开任务管理器 → 清自启 → 删目录 → 问你要不要删记录。

手动清干净：

```powershell
Stop-ScheduledTask -TaskName MythclassClient -ErrorAction SilentlyContinue
Stop-ScheduledTask -TaskName MythclassGuard -ErrorAction SilentlyContinue
schtasks /Delete /TN MythclassClient /F
schtasks /Delete /TN MythclassGuard /F
Get-Process Mythclass -ErrorAction SilentlyContinue | Stop-Process -Force
Remove-Item "$env:ProgramFiles\Mythclass" -Recurse -Force
Remove-Item "$env:APPDATA\Mythclass" -Recurse -Force
Remove-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Policies\System' -Name DisableTaskMgr -ErrorAction SilentlyContinue
```

## 八、故障排查

| 现象 | 怎么办 |
|---|---|
| 托盘没图标 | 看 `client.log`；`pystray`/`Pillow` 装了吗 |
| 一直「重连中」 | 一体机能不能打开 `https://mythclassapi.ryokuryuneko.top/healthz` |
| 装了但没自启 | `schtasks /Query /TN MythclassClient` 看任务在不在 |
| 关掉又自己起来 | 正常，这是进程保护。想停就在托盘里用密码退出（退出后它不会再来） |
| 任务管理器打不开 | 有人开过这个开关。设置里取消勾选，或者卸载脚本会自动清掉 |
| 屏幕流黑屏 | 计划任务要以用户会话身份跑，不能是 Session 0 的服务 |
| 文件记录没有 | 确认 `watchDirs` 里的目录真的存在 |
| 音频空 | 装 `pycaw`；或真没声音 |
| 系统时间不准 | JWT 校验会失败，把时间同步打开 |

## 九、合规

客户端能看屏幕、能记文件。装之前请确认：

- 学生知道有这个东西
- 学校同意了
- 只在正常教学管理里用

设置里有个「合规使用承诺」勾选项，就是这个意思。别当它不存在。
